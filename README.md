# Personalized Learning Path & Assessment Planner

## Project 48 — Design and Analysis of Algorithms

A C-based learning planner that analyzes a student's performance and creates a **personalized study plan** based on assessment scores, topic difficulty, prerequisites, and available study time.

## Main Features

- Student assessment
- Weak and strong topic analysis
- Topic priority calculation
- Prerequisite graph
- Dependency Risk Detector
- Personalized learning path
- Study-time optimization
- Explainable recommendations
- Re-assessment and progress comparison
- Adaptive re-planning
- What-If Study Simulator
- Progress dashboard

## Project Modules

**Part 1 — Student Analysis**  
Analyzes assessment scores, identifies weak/strong topics, calculates priorities, and checks prerequisite risks.

**Part 2 — Personalized Planning**  
Generates a personalized learning path and uses **0/1 Knapsack** to optimize the study plan according to available time.

**Part 3 — Adaptive Intelligence**  
Re-assesses student performance and automatically updates priorities and study plans based on improvement.

## Algorithms Used

- Graph / Adjacency Matrix
- DFS / Recursive Graph Traversal
- 0/1 Knapsack using Dynamic Programming
- Linear Search
- Priority-based recommendation logic

## Technology

- **Language:** C
- **Compiler:** GCC / MinGW
- **Interface:** Terminal-based UI
- **Version Control:** Git & GitHub
